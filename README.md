# Hirut Mesfin — Portfolio Website

A responsive portfolio website for Hirut Mesfin, UI/UX Designer and Frontend Developer.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — colors, layout, responsive styling, and project mockups
- `script.js` — mobile navigation, current year, and subtle scroll reveal effects

## Preview locally
1. Extract the ZIP file.
2. Open the `hirut-portfolio` folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

No build step is required. Google Fonts are loaded from the internet; the page falls back to system fonts if unavailable.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `hirut-portfolio`).
2. Upload the contents of this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site and open the URL shown in Pages settings.

You can also deploy the folder to Vercel or Netlify.
